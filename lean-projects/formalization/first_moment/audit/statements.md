## Definitions and source-level hypotheses to preserve

The model has `k ≥ 2`, a deterministic sequence of nonnegative integer pile vectors summing to `N`, independent uniform fixed-column permutations, `K = floor(T log N)`, legal prefix words, an ambient legal prefix `w`, and two independent graphs generated by this model. The ambient parameters are `r,b`, with the source expected-size normalization, and times obey `r ≤ s ≤ u ≤ T`.

The time-profile costs remain exactly `A(r,s)` and `B_theta(r,s)`, with

* `beta(s) = b - A(r,s)`;
* `f1(s,u,theta) = ((theta+3)/2) beta(s) - B_theta(s,u) - 2 B_2(u,T)`;
* `f2(s,u,theta) = ((theta-1)/2) beta(s) - B_theta(s,u) - 2 B_2(u,T)`;
* `N1(s,u) = sInf (f1(s,u) '' Icc 3 4)`;
* `N2(s,u) = sInf (f2(s,u) '' Icc 3 4)`;
* `N3(s) = beta(s) - B_2(s,T)`.

`FM(r,b,T,eta)` includes all four source conditions: `beta(T) ≤ -eta`; `N1(s,u) ≤ -eta`; `N2(s,u) ≤ -eta`; and `N3(s) ≤ -eta`, over their stated time domains. No homogeneous identity such as `psi(theta)=2 psi(2)` is included. No attained optimizer or continuity in theta is needed for numerical assembly.

For the probabilistic theorem, preserve the source hypotheses of an almost-time-profile-like deterministic tail for the chosen regular partition, the local good-shuffle condition, and `FM`. The order of choices is fixed `k,T,eta,gamma`, then `chi`, then its `alpha_chi`, then the remaining small parameters, finally `N`. All profile errors must be uniform over retained profiles. An arbitrary unqualified family of measures is not by itself a Lean measurable/integrable profile; any such analytic obligations must be found in the incoming profile definitions/theorems, rather than added opportunistically to the final theorem.

## Exact algebra interfaces suitable for freezing

The following are real-algebra theorems. Their hypotheses are explicit earlier-lemma conclusions, not replacement assumptions of the shuffle model. All variables in this subsection are real. Write `V` for the boundary size exponent, `L` for the extension size exponent, `F` for the common boundary fluctuation exponent, `S,Q,H` for profile statistics, `E` for the tail exponent, `beta` for the maximal-pile bound, `B` for `B_theta(s,u)`, and `D` for `B_2(u,T)`.

1. **Large exponent, fixed theta.** Assume `0 ≤ e`, `0 ≤ delta`, `3 ≤ theta ≤ 4`, `0 ≤ Q`, `L ≤ V-S-Q+e`, `L-F ≤ delta`, `V ≤ beta+e`, `V/2-e ≤ F`, `E ≤ -D+e`, and `H ≤ theta*S-B+e`. Conclude

   `4*L-F+2*E+H ≤ ((theta+3)/2)*beta-B-2*D + 12*e+delta`.

   A convenient derivation rewrites the left algebraic part as `theta*(L+S)+(4-theta)*L-F`. This avoids needing the other side of the approximate size identity. The exact worst error coefficient from these assumptions is `23/2`; `12` is a transparent uniform bound. The theorem itself does not need `L ≥ 2 delta`; that condition belongs to the edge-density routing theorem.

2. **Small nonsingleton exponent, fixed theta.** Assume `0 ≤ e`, `3 ≤ theta ≤ 4`, `S ≤ V-F+e`, `V ≤ beta+e`, `V/2-e ≤ F`, `E ≤ -D+e`, and `H ≤ theta*S-B+e`. Conclude

   `-F+2*E+H ≤ ((theta-1)/2)*beta-B-2*D + 14*e`.

   The exact largest error coefficient is `27/2`. The first-crossing origin of `S ≤ V-F+e` must be proved upstream; it is not available for arbitrary stable terminal fallback words.

3. **Singleton exponent.** Assume `V ≤ beta+e`, `E ≤ -D+e`. Conclude `V+E ≤ beta-D+2*e`. Combine with `beta-D ≤ -eta` to obtain `V+E ≤ -eta+2*e`. For a terminal word, either apply the same statement at `s=T`, or use the separate facts `E=0` and `V ≤ beta(T)+e`.

4. **Infimum assembly.** For any `f : Real -> Real`, reals `X,loss,eta`, assume `X ≤ f theta + loss` for every `theta ∈ Icc 3 4`, and `sInf (f '' Icc 3 4) ≤ -eta`. Conclude `X ≤ -eta+loss`. The image is nonempty, and `X-loss` is already a lower bound of that image. Consequently `le_csInf` proves the result without adding continuity, compactness, existence of a minimizer, or a `BddBelow` model hypothesis. A near-minimizer proof is unnecessary.

5. **Terminal fallback exclusion.** Assume `0 < delta`, `0 ≤ e`, `3*e ≤ eta`, `L ≤ betaT+e`, `betaT ≤ -eta`, and `L/2-e ≤ F`. Conclude `L-F < delta`. This rules out the source terminal-fallback inequality in a nonterminal retained pair.

6. **Common negative margin.** Applying items 1–4 with `14*e+delta ≤ eta/2`, `e,delta ≥ 0`, yields all source exponents at most `-eta/2` and therefore at most `-eta/4` when `eta>0`. This is an explicit error-budget corollary, not a new restriction on model parameters: the incoming uniform profile estimates and the source hierarchy must establish its premise.

Do not identify the singleton fluctuation exponent with an arbitrary real for a terminal pair: the source allows `-infinity` there. Terminal singleton assembly uses only `V,E,beta,D`, so it avoids this type/domain problem entirely.

## Finite counting statements for the proposed encoding

The parent proposed the following precise coding; this section records its cardinality consequences.

Define

`Sparse K k q = Sigma (Q : {S : Finset (Fin K) // S.card ≤ q}), (Q.val -> Fin k)`

and

`A(K,k,q) = sum_{j in range(q+1)} (K.choose j) * k^j`.

The natural number `q` need not satisfy `q ≤ K`: choose coefficients with `j>K` vanish.

The complete finite statement list is:

* **Sparse cardinality:** `Fintype.card (Sparse K k q) = A(K,k,q)` for all natural `K,k,q`.
* **Weighted sparse bound:** for real `0<t≤1`, `t^q * (A(K,k,q):Real) ≤ (1+(k:Real)*t)^K`.
* **Inverse weighted bound:** under the same assumptions, `(A(K,k,q):Real) ≤ (t^q)^(-1) * (1+(k:Real)*t)^K`.
* **Boundary stop type:** `Stop K k qb = Fin(K+1) × Fin(k+1) × Sparse K k qb`. The extra digit value can encode “no genuine crossing.”
* **Class key:** two stop encodings, `Fin(K+1)` for extension length, `Fin d -> Fin(K+1)` for counts, `Sparse K k qe` for exceptional positions and their digit values, and `Fin 4` for routing.
* **Exact class-key cardinality:** `card ClassKey = 4*(k+1)^2*(K+1)^(d+3)*A(K,k,qb)^2*A(K,k,qe)`.
* **Injection consequence:** if a finite class type `C` has an injective function into this precise `ClassKey`, its cardinality is at most that expression. Encoding injectivity for actual retained shuffle classes is a separate proof obligation, not a model hypothesis to conceal in the final theorem.

Useful verified trusted dependencies include `Finset.card_powersetCard`, `Fintype.card_sigma`, finite function-space cardinality, and `Fintype.card_le_of_injective`. The binomial expansion supplies the weighted sparse bound.

For the asymptotic corollary, after fixing `chi`, the number `d=R(m+1)k` of coarse count entries is fixed. The source cutoff counts obey `qb ≤ (C/log(1/chi))*log N` and `qe ≤ alpha_chi*log N`, while `K ≤ T log N`. Applying the weighted bound with a small auxiliary `t`, first choose `t` so that `T log(1+kt)` is small and then `chi` so that both cutoff coefficients times `log(1/t)` are small. The fixed polynomial in `log N` has exponent `o(log N)`. This proves the required eventual `#C ≤ N^epsilon` with the source order of limits. Avoid assuming this final count as a new shuffle hypothesis.

The exceptional digit **values** must be included in the code. The displayed source definition mentions only the exceptional set, but the final first-moment proof explicitly says exceptional digit values are counted. This refinement implements that stated bookkeeping. Counts and representative probabilities do not make actual `c_L` exactly constant in a class: its good-coordinate contribution varies by the regular-partition error. Apply the numerical margin separately per word, with the common `H`, or use the four routing values to split classes. Do not copy the homogeneous proof's assertion of exact class constancy.

## Fixed-class entropy count without a multinomial detour

A direct product-weight proof may be simpler than proving the full combinatorial multinomial identity. The exact helpers to freeze are:

1. For `W : Finset (Fin K -> Fin k)` and real weights `p(j,l) ≥ 0` with `sum_l p(j,l)=1` for every position, the sum of `prod_j p(j,w(j))` over all words is `1`.
2. Under the same conditions, if every word in `W` has common mass `m`, then `(W.card:Real)*m ≤ 1`.
3. If moreover `0<m`, then `(W.card:Real) ≤ m^(-1)`.
4. Given `cell : Fin K -> Fin d` and natural counts `n : Fin d -> Fin k -> Nat`, let `W` consist exactly of words whose counts of `(cell(j),w(j))=(a,l)` equal `n(a,l)`. Set `nTot(a)=sum_l n(a,l)` and

   `entropy = sum_a ((nTot(a):Real)*log(nTot(a)) - sum_l (n(a,l):Real)*log(n(a,l)))`.

   Then `(W.card:Real) ≤ exp(entropy)`. There is no compatibility assumption: an inconsistent count array gives an empty class. For a nonempty class, compatibility follows by summing its defining counts. Zero counts use `0*log 0 = 0`.
5. For a nonempty such class and `k>0`, define empirical probabilities in nonempty cells by `n(a,l)/nTot(a)` and use a uniform distribution in empty cells. They are row-stochastic, and each word's mass is exactly `exp(-entropy)`.

Exact trusted normalization dependencies found in cached mathlib are `Fintype.prod_sum` and `Finset.prod_sum` in `Mathlib/Algebra/BigOperators/Ring/Finset.lean`. There is `Nat.multinomial` and `Finset.sum_pow`, but no ready entropy/multinomial cardinal bound was found. Thus item 4 is genuine work, not an existing theorem name.

For an actual profile, exceptional coordinates and their digits are fixed, so remove those coordinates, apply item 4 to the good coordinates and their space-time cells, then reinsert fixed exceptional digits. The entropy in the source is exactly `entropy/log N`. The conversion from `exp(entropy)` to `N^H` needs `N>1` and the exact definition of `H`.

## Exact finite first-moment assembly

Separate generic finite probability algebra from the stochastic shuffle theorem.

Let `M` be a finite edge type, `I` a finite retained block index type, `C` a finite class type, and `classOf : I -> C`. Let real arrays `p(m),discard(m),q(i,m)` be nonnegative. For each edge take `J(m) : Finset I`, assume `#J(m) ≤ L`, and assume

`p(m) ≤ discard(m) + sum_{i in J(m)} q(i,m)`.

Then the exact finite-sum theorem is

`sum_m p(m)^2 ≤ 2*sum_m discard(m)^2 + 2*L*sum_c sum_{i:classOf(i)=c} sum_m q(i,m)^2`.

Consequently, if the discarded-square sum is at most `D`, and every class's square sum is at most `U`, then

`sum_m p(m)^2 ≤ 2*D + 2*L*(card C)*U`.

The proof uses `(a+b)^2 ≤ 2a^2+2b^2`, finite Cauchy–Schwarz, extension of a nonnegative partial sum, and sum rearrangement. No maximum over an empty class family is needed. Both localization multiplicity `L` and the number of classes occur and must be retained in the bookkeeping.

For probability, take a finite sample type `Omega`, weights `w(omega) ≥ 0` summing to `1`, and a decidable edge predicate `edge(omega,m)`. Define independent copies by product weights `w(omega)w(omega')`. Then

`E_{w×w} [card {m | edge(omega,m) and edge(omega',m)}] = sum_m (sum_omega w(omega)*indicator(edge(omega,m)))^2`.

This equality together with the finite-sum theorem yields an exact **conditional assembly interface**. It is not yet `prop:ub-first-moment` until the arrays and every localization/density/counting premise are instantiated by proved shuffle-model results.

The elementary power corollary, for `N>1`, is

`D≤N^(-d), L≤N^ell, #C≤N^c, U≤N^(-a)`

implies

`E commonEdges ≤ 2*N^(-d) + 2*N^(ell+c-a)`.

For fixed `0<deltaStar<min(d,a-ell-c)`, the right side is eventually at most `N^(-deltaStar)`. The factors `2` and the addition require this final absorption or an explicit threshold; they cannot disappear by algebra alone.

## Explicit upstream obstruction

Take `k=3`, `3|N`, ambient root, and uniform ternary columns. The allowed boundary pair `y=z=(1)` has a genuine left and right crossing in its **first** column. For every continuation `x=(1,0,...,0)`, the left endpoint of its interval is the deterministic boundary `N/3` (up to the indexing convention), whereas the source fluctuation exponent is

`F = (1/2) log_N(N/3)`.

Choose the first-crossing length so `L-F<delta` but the parent gap is at least `delta`. It is a stable large block, all selected digits are good, and `F` tends to `1/2`. Its conditional left-endpoint atom on the event `S_x` is exactly `P(S_x | U_x)`. Taking expectation contradicts the asserted `N^(-1/2+O(delta)+o(1))` anti-concentration bound, since `P(S_x)` tends to one.

The small density statement also fails, not just its proof. Keep the first and all columns after the second uniform ternary, but set the second-column pile sizes to `(2, (N-2)/2, (N-2)/2)` along an even multiple-of-three subsequence. Let `x=(1,0)` and the same `y=z=(1)`. Then

* `F = (1/2)log_N(N/3)`;
* `L = log_N(2/3)=o(1)`, so this is a small nonsingleton first-crossing block;
* exactly one exceptional coordinate is used, so `R_x=1/log N` passes the retained cutoff;
* the block starts deterministically at `N/3`.

With probability `(N/3)_2/(N)_2`, asymptotic to `1/9`, both rows assigned second-column digit zero have first digit one. Conditional on that event, they have identical remaining strings with probability

`((N/3-1)/(N-1))^(K-2) = N^(c_E+o(1))`.

Consequently the fixed boundary edge has squared probability at least `N^(2*c_E+o(1))`. The printed small density bound would instead be `N^(-F+2*c_E+O(delta)+o(1))`, a contradiction after fixing sufficiently small `delta`.

A single altered column changes the almost-profile counts by only `O(1/log N)`. Every column is good. For the uniform ternary time profile, `T>3/(2 log 3)` with a positive buffer satisfies the actual variational `FM` conditions. Thus the counterexample respects the intended model assumptions; it is not repaired by choosing a larger `N` or by invoking the time-inhomogeneous margins.

A possible upstream proof reorganization is to reveal a first good column, condition its partition, and restart suitable boundary constructions inside those blocks. This needs a new valid localization/conditioning argument; it does not justify assuming the currently false estimate.

One alternate algebraic target preserves the variational assumptions: if a replacement density theorem yielded a nonsingleton exponent `3L+2E`, then the same `N1` margin closes because

`3L+theta*S ≤ 3V+(theta-3)S-3Q+error ≤ theta*V+(3-theta)F+error ≤ ((theta+3)/2)*beta+error`.

This only identifies a possible algebraic interface. Such a density theorem is not proved in the supplied sources and should not be frozen as an available input.

## Whole-proof placement and random cuts

The deterministic upper proof routes the first moment through conditional preservation, conditional first moments, the Portenko/shared-edge exponential moment, sparsity, and the truncated chi-square comparison. Those later theorems do not fix a false first-moment input.

The lower proof has separate largest-prefix-block and cold-spot branches; the latter uses the variational witness, tilted type counts, bridge/localization results, collision moments, and the ascent test. The numerical first-moment interfaces above do not claim to prove either lower branch.

The random-pile extension averages a **uniform total-variation bound** over good deterministic cut realizations and adds the probability of the bad event. High probability `1-o(1)` is sufficient for that extension. It is not by itself enough for a polynomial unconditional expected-common-edge bound: the crude bad-event contribution is of order `N*P(bad)`. Do not claim the assigned deterministic first-moment rate transfers to arbitrary random cuts under only the source high-probability assumption.
